# Проект ОПП
## Описание
Использование классов и объектов на основе популярной темы e-commerce.
E-commerce — электронная торговля, или электронная коммерция. 
На данном этапе работы мы не будем реализовывать систему платежей, 
однако подготовим всё для того, чтобы у нас появилось ядро для интернет-магазина. 
В дальнейшем для этого ядра возможно будет реализовать любой интерфейс — 
от сайта до телеграм-бота.
___
## Модули
- category
- product
- read_json - с функцией чтения json-файла с категориями

## Классы
- class Category в модуле category для создания категорий
  с атрибутами name: str,
      description: str,
      products: list,
      category_count = 0,
      product_count = 0.
- class Product в модуле product для создания продуктов в Категориях
    с атрибутами name: str,
    description: str,
    price: float,
    quantity: int.
___
## Описание class Category
### Методы
- init - Метод для инициализации экземпляра класса. Задаем значения атрибутам экземпляра.
- add_product - Метод для добавления продукта в категорию.
- str - магический метод для строкового вывода экземпляра класса.
### Геттеры, сеттеры, делитеры
- products - Getter, который возвращает строку, информацию по продуктам.
- prod_in_list - Getter, который возвращает словарь, информацию по продуктам
___
## Описание class Product
### Методы
- init - Метод для инициализации экземпляра класса. Задаем значения атрибутам экземпляра.
- new_product - Класс-Метод для добавления продукта в класс Product.
- str - магический метод для строкового вывода экземпляра класса.
- add - магический метод для сложения общей цены для продуктов (цена*кол-во).
### Геттеры, сеттеры, делитеры
- price - Getter, который возвращает информацию по цене.
- price - Setter, который проверяет цену на положительность, возвращает вывод с ошибкой.
___
## Описание class Iterator
### Методы
- iter - Метод для получения итератора для перебора объекта.
- next - Метод для перехода к следующему значению и его считывание.

## Тесты
Проект включает набор тестов для проверки корректности работы.
### Запуск тестов
Для запуска тестов установите pytest:
```
pip install -U pytest
pip install pytest-cov
```
### Структура тестов
Тесты расположены в директории `tests/` и включают проверки для:
* основных функций
* граничных случаев
* обработки ошибок
### Требования
Для запуска тестов необходимы:
```
pytest
pytest-cov
```
### Покрытие тестами
Для проверки покрытия используйте:
```
pytest --cov
```
Для создания html-отчета используйте:
```
pytest --cov=src --cov-report=html
```
